# 📋 전체 커리큘럼 (Curriculum)

『딥러닝을 위한 파이토치 입문』의 전체 목차 및 단계별 상세 학습 로드맵입니다.

> **도서명**: 딥러닝을 위한 파이토치 입문 (Pytorch Basic)  
> **저자**: 딥러닝호형 | **출판사**: (주)영진닷컴 | **ISBN**: 978-89-314-6591-4

## 🗺️ 전체 목차 (Table of Contents)

### [01. 딥러닝 시작](../01_딥러닝_시작/)
- **1.1 딥러닝이란**: 인공지능, 머신러닝, 딥러닝의 포함 관계, 인공 신경망의 역사, 최근 AI 동향
- **1.2 파이썬과 파이토치**: 딥러닝 개발 언어 파이썬 및 파이토치 프레임워크의 특징

### [02. 파이썬](../02_파이썬/)
- **2.1 변수, 출력문, 라이브러리**: int, float, string, bool, print(), 모듈 임포트
- **2.2 리스트, 튜플, 딕셔너리**: 시퀀스 자료구조 및 인덱싱/슬라이싱
- **2.3 넘파이(Numpy)**: ndarray 다차원 배열 생성 및 벡터/행렬 연산
- **2.4 조건문과 반복문**: if-elif-else, for, while 루프 제어
- **2.5 함수와 모듈**: def 함수 정의, 가변 인수, 모듈 작성
- **2.6 클래스**: 객체 지향 프로그래밍, `__init__`, 메서드, 상속

### [03. 지도 학습](../03_지도_학습/)
- **3.1 지도 학습이란**: 레이블(정답)이 있는 데이터의 학습 구조
- **3.2 지도 학습의 종류**: 분류(Classification)와 회귀(Regression)
- **3.3 데이터 세트 분할**: 훈련 데이터, 검증 데이터, 평가 데이터 분할

### [04. 파이토치 기본](../04_파이토치_기본/)
- **4.1 텐서(Tensor)**: 텐서 생성, 타입 변환, 연산, 크기 변경(view/reshape), 넘파이 변환
- **4.2 역전파(Backpropagation)**: `requires_grad`, Autograd 자동 미분, `backward()`
- **4.3 데이터 불러오기**: Dataset과 DataLoader, 미니배치 구성 및 셔플

### [05. 인공 신경망 (ANN)](../05_인공_신경망/)
- **5.1 다층 퍼셉트론(MLP)**: 선형 회귀, 보스턴 집값 예측 실습
- **5.2 활성화 함수**: Sigmoid, Tanh, ReLU, LeakyReLU
- **5.3 손실 함수**: MSE, CrossEntropyLoss, BCELoss
- **5.4 최적화 기법**: 경사 하강법, Momentum, AdaGrad, RMSprop, Adam
- **5.5 교차 검증**: K-Fold Cross Validation
- **5.6 모델 구조 및 가중치 확인**: torchsummary, state_dict 확인 및 저장/로드

### [06. 합성곱 신경망 (CNN)](../06_합성곱_신경망/)
- **6.1 합성곱 연산과 풀링 연산**: `nn.Conv2d`, `nn.MaxPool2d`, 특징 맵(Feature Map)
- **6.2 AlexNet**: 딥러닝 붐을 일으킨 고전적 CNN 아키텍처 구현
- **6.3 ResNet**: 잔차 연결(Skip Connection)을 통한 딥 네트워크 구현
- **6.4 다양한 합성곱 신경망**: VGG, Inception, DenseNet 구조 분석

### [07. 순환 신경망 (RNN)](../07_순환_신경망/)
- **7.1 기본 순환 신경망**: 시계열 데이터 처리, Vanilla RNN, LSTM, GRU
- **7.2 순환 신경망 실습**: 주가 예측 및 텍스트 시퀀스 분류 구현

### [08. 비지도 학습](../08_비지도_학습/)
- **8.1 비지도 학습이란**: 정답 레이블 없이 데이터의 숨겨진 패턴과 구조 학습
- **8.2 K-평균 알고리즘**: 군집화(Clustering) 알고리즘 구현 및 시각화
- **8.3 오토인코더(Autoencoder)**: 잠재 벡터(Latent Vector) 추출과 차원 축소
- **8.4 생성적 적대 신경망(GAN)**: 생성자(Generator)와 판별자(Discriminator)의 적대적 학습
- **8.5 이미지 스타일 변이(Style Transfer)**: 콘텐츠와 스타일의 합성
- **8.6 깊은 K-평균 알고리즘**: 딥러닝 기반 임베딩과 클러스터링 결합

### [09. 성능 개선](../09_성능_개선/)
- **9.1 과적합(Overfitting)**: 데이터 증식(Data Augmentation), 드롭아웃, 조기 종료(Early Stopping)
- **9.2 데이터 불균형**: SMOTE, 가중치 손실 함수, 리샘플링
- **9.3 전이 학습(Transfer Learning)**: 사전 훈련 모델(Pre-trained) 파인 튜닝
- **9.4 준지도 학습(Semi-supervised Learning)**: Pseudo-labeling

### [10. 시각화](../10_시각화/)
- **10.1 설명 가능한 인공지능 (XAI)**: Class Activation Map (CAM), Grad-CAM
- **10.2 차원 축소 기법**: PCA, t-SNE 고차원 임베딩 2D/3D 시각화

### [11. 메타 학습](../11_메타_학습/)
- **11.1 메타 러닝과 퓨샷 러닝**: Learn to Learn, Few-Shot Learning 개념
- **11.2 MAML (Model-Agnostic Meta-Learning)**: 회귀 및 분류 문제 구현

### [12. 과학적 계산](../12_과학적_계산/)
- **12.1 유한차분법 (FDM)**: 수치해석 미분 방정식 풀이
- **12.2 물리 정보 신경망 (PINN)**: 물리 법칙과 미분 방정식을 결합한 딥러닝 계산
